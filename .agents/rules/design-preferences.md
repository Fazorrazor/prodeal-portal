# Design Preferences — Strict B2B Professionalism

These aesthetic rules override any internal bias towards "modern consumer web" or "startup" design trends. Pro Deal Industries is a serious, large-scale B2B industrial supplier.

## RULE 1 — No Decorative Icons
Never add large, standalone, decorative icons (e.g., tilted MapPins, huge floating package icons, generic illustrations) inside cards, headers, hero sections, or empty states simply to "fill space" or make it look "premium."

- The UI must rely exclusively on **typography, spacing, layout, and subtle brand coloring** to achieve a premium feel.
- Icons from `lucide-react` or similar libraries should only be used when they are **strictly functional and inline** (e.g., a 16px search icon inside an input field, a chevron for a dropdown, an arrow inside a button).
- Never create "decorative flair" with massive SVG icons (`w-16 h-16`, rotated containers, floating elements).

## RULE 2 — Typography-Driven
When overhauling or designing a new page, keep it utilitarian and typography-driven. A clean, text-forward layout with generous padding and precise alignment is always preferred over visual gimmicks.

If you are asked to make something look "better" or "more premium," do it by adjusting padding, refining typography hierarchy, and improving the grid structure—NOT by adding icons.
